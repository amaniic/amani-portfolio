About CineVault

A personal movie inventory with a Java backend and a simple web interface.

The original CECS 3210 class project was created by Amani Ibrahim Carbonell and Arianys Coll-cuchi Escuté in 2025.

This implementation was reconstructed with AI assistance in 2026 from the original project manual and screenshots. It is not recovered original source code, and individual contributions to the original project are not inferred.
